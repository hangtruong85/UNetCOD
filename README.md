## 🔍 Overview

UNETCOD is an efficient segmentation framework built upon the UNet3+ architecture, extended with a **Dual-Attention** mechanism and **Boundary Enhancement** module. It is designed to address the challenging task of military camouflage object segmentation, where targets are visually similar to their surrounding environment.
